Motionly install

Install Motionly locally.

Motionly is an open source AI motion graphics editor that runs on your own machine. One command scaffolds a project, opens the local editor, and gives you an editable .motion file you can animate visually, hand to an AI agent, and export to MP4.

Keep your images, video, SVGs, GIFs, and audio inside the project assets/ folder so every animation stays portable and version-controlled alongside your code.

Install Try Demo

Requirements

  • Node.js 20.19.0 or newer and npm for the CLI and local editor.
  • FFmpeg on your PATH to render the timeline to MP4.
  • Any modern browser — the editor runs at localhost.

No account, API key, or cloud upload is needed to install and edit. You can create projects, animate, and preview fully offline.

What you get

  • A readable project.motion file describing scenes, layers, keyframes, and easing.
  • A visual canvas and timeline for adjusting position, timing, and motion by hand.
  • An assets/ folder for local media instead of remote URLs.
  • Local MP4 export, so finished animations never leave your machine.

The Motionly workflow

Generate a draft, edit it visually, then export — in four steps.

1. Describe the animation

Prompt Motionly with the motion you want — a logo reveal, a feature walkthrough, a social clip — and it writes the scenes, layers, and keyframes into your .motion project.

2. Edit on the canvas

Move layers, retime keyframes, and change easing directly in the editor. Nothing is baked into an opaque render, so every property stays adjustable.

3. Iterate with an AI agent

Because the project is readable text, agents like Claude Code, Codex, or Antigravity can change one keyframe without rewriting the whole animation.

4. Export to MP4

Render the timeline locally with FFmpeg and drop the result into a launch page, a demo, or a social post.

Assets folder

Put project media in assets/ and reference it from project.motion.

my-video/
  project.motion
  assets/
    logo.svg
    product-shot.png
    soundtrack.mp3
  • Place images, videos, SVGs, GIFs, Lottie files, and audio in assets/.
  • Use clear filenames and keep original aspect ratios.
  • Save visual edits back to project.motion for version control.
  • Commit both the project file and the assets folder so teammates and agents get identical results.
